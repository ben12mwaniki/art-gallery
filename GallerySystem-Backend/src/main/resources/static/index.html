Online Art Gallery API

A RESTful backend for an online art marketplace connecting artists and customers. The API provides artwork management, shopping carts, checkout, orders, and user management.

Open API Documentation View on GitHub

API Capabilities

Artwork Create, browse, and manage artwork listings.
Shopping Cart Manage cart items and requested quantities.
Checkout Convert a customer's cart into a completed order.
Order History Retrieve completed purchases and purchase-time information.
Built with Spring Boot, Java, PostgreSQL, and Docker.
